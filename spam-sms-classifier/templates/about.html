About Spam SMS Classifier

Designed to help users identify suspicious SMS content before it becomes a problem.

Project Goal

This application demonstrates how machine learning and natural language processing can be used to classify SMS texts as spam or legitimate communication.

Technology Stack

Python, Flask, Scikit-learn, TF-IDF vectorization, MySQL, and a responsive frontend dashboard.

How It Works

User messages are processed through a trained vectorizer and classifier, producing a prediction with a confidence score and a record saved in the database for analytics.
